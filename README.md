Use the **Privacy Policy** URL in Google Play Console after confirming the deployment is live. The policy describes the current local-processing version of LipTry; it does not promise that future versions will never introduce online services.

## Repository contents

- `privacy.html` — the full English privacy policy, including data access, use, sharing, retention, deletion, and contact information.
- `index.html` — a small landing page linking to the policy.
- `styles.css` — shared responsive styles, using only locally available system fonts.
- `.nojekyll` — serves the static files without Jekyll processing.

The website is pure HTML and CSS. It has no JavaScript, analytics, trackers, advertisements, external font requests, forms, or cookies added by this site. GitHub Pages handles hosting requests under GitHub's own privacy practices.

## GitHub Pages deployment

Publish this public repository with **Deploy from a branch**, branch **main**, folder **/(root)**. No custom domain or build tool is required.

If Pages needs to be configured manually:

1. Open this repository on GitHub.
2. Go to **Settings → Pages → Build and deployment**.
3. Set **Source** to **Deploy from a branch**.
4. Select **main** and **/(root)**, then select **Save**.
5. Wait for the Pages deployment to finish and open both URLs above in a signed-out browser. Confirm HTTPS, the page content, and the contact email.

To preview locally, open `index.html` or `privacy.html` in a browser. Both also work directly from a static HTTP server.

## Maintenance

`privacy.html` is the authoritative published policy; the policy previously in this README is preserved in Git history. Keep the policy and any in-app disclosures accurate before releasing features that change data handling. Update the effective date when the policy changes.

This repository is only for public privacy information. Do not add App source code, user photos, credentials, tokens, passwords, signing keys, or Play Console data. The separate LipTry App repository is not part of this site.
